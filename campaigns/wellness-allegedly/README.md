# Wellness, Allegedly campaign

Put the **white** logo from the campaign's zip folder in this folder and name
it `logo.png`. It's shown small at the top of each clip for the first
4 seconds (the brief's optional "Wellness, Allegedly" tag).

Run `Clipper.command`, pick this campaign, and paste the episode link.
You get 15 clips in `clips/<episode>/TikTok`, `/Instagram` and `/YouTube`,
plus `clips.txt` with the text to paste when posting each one.

Before posting, check every clip against the brief: no rage-bait or
men-vs-women framing, nothing out of context, captions readable.
